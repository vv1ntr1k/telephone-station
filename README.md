# Система Телефонная станция

Проект моделирует работу телефонной станции.

## Функционал
- Администратор подключает абонентов
- Администратор просматривает неоплаченные счета
- Администратор блокирует абонентов
- Абонент выбирает одну или несколько услуг
- Абонент оплачивает счета за разговоры и услуги

## Назначение
Проект разработан для удобства работы телефонной станции.
